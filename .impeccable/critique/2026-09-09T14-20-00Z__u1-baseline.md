## Combined verdict

The interface does not read as generated UI. It rejects cards, gradients,
glass, rounded chrome and sports-dashboard decoration with a coherent physical
board language. The deterministic scan returned no findings in the four U1
source files or the live login route.

Cognitive load is moderate: three of eight checks fail. Home needs stronger
grouping and hierarchy, and create/join remain fully expanded when a returning
member mainly needs an existing league. No decision point exceeds four options.

## U1 priorities

1. **P1: restore the marker's meaning.** Setup is unsettled and should use the
   waiting rule; drafting is a status word, not an on-the-clock live slot.
2. **P1: lead with the returning-member task.** Add a real page title and make
   the league board the first framed task. Create and join stay secondary.
3. **P1: make navigation legible to touch.** Rail actions and whole-row links
   need 44px targets and persistent wording or a drawn arrow.
4. **P2: give desktop deliberate task blocks.** Framed Banks should group the
   board and forms without widening the one-measure shell.
5. **P2: explain the Google handoff.** One short sentence should say that Google
   verifies identity and the invite code takes the slot.
